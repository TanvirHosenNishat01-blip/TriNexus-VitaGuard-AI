## 📌 Project Overview

**VitaGuard AI** is an **Explainable Artificial Intelligence (XAI)-based healthcare decision support system** designed for **early diabetes risk screening**.

The system analyzes patient health information including:

- Age
- BMI
- Glucose Level
- Blood Pressure
- Lifestyle Factors
- Health History

Using Machine Learning models, VitaGuard AI predicts diabetes risk levels and provides transparent explanations using **SHAP (SHapley Additive exPlanations)**.

The goal is to assist healthcare professionals in early risk identification while ensuring that final medical decisions remain with qualified healthcare providers.

# 🎯 Key Objectives

| Objective | Description |
|---|---|
| Early Detection | Identify individuals at higher diabetes risk before severe complications occur |
| AI Assistance | Provide machine learning-based risk prediction |
| Explainability | Explain why AI generated a specific prediction |
| Healthcare Support | Assist doctors and healthcare workers in decision-making |

# 🚀 Main Features


| Feature | Description |
|---|---|
| 🧠 Diabetes Risk Prediction | Predicts diabetes probability using ML models |
| 📊 Risk Classification | Classifies patients into Low, Medium, and High risk categories |
| 🔍 Explainable AI | Uses SHAP to explain model decisions |
| 📈 Feature Importance | Visualizes important health factors affecting prediction |
| 🏥 Healthcare Dashboard | Provides an interactive patient analysis interface |
| 🤖 Decision Support | Helps healthcare professionals make informed decisions |
